# OpenFrame 0.17.0

This release refines administrator controls, sharing, and navigation for larger workspaces.

- Only global admins can create groups. Admins automatically administer every group and have unrestricted access to all content and settings; group controls cannot reduce or remove their access. Existing identities, credentials, ownership, and explicit memberships are preserved.
- The sidebar displays the signed-in name beside the version and sign-out control.
- Manage access has separate Groups and Users menus. Access tags show shared groups and directly assigned users who do not already inherit access through a granted group.
- Admins use Add existing user to assign memberships. User dragging is removed; admin group dragging remains. A missing direct membership displays a + button with confirmation in the user access editor.
- User content access is grouped into Slides, Playlists, Screens, Media, and Folders. Admin accounts show unrestricted access and Group admin status.
- Playlist actions use a compact, aligned toolbar. The playlist publication reminder and slide draft-library text are removed. Hover or focus Live to see the published playlists assigned to online screens that make the slide live.

## Upgrade

Player **0.10.11 remains compatible and unchanged**. This server release does not require a new APK or alter player manifests. Shapes, stocks, and vertical weather introduced in 0.16.0 still require player 0.10.11 or newer.

Back up the complete application data directory and preserve the existing Compose project name, data volume, PUBLIC_URL, COOKIE_SECURE, and player pairing. Never use `down -v` for an upgrade. After publication, installations following `ghcr.io/verodus/openframe:latest` can pull and recreate the server:

```sh
docker compose -f compose.registry.yaml pull
docker compose -f compose.registry.yaml up -d
```

Use the same Compose file and project arguments as your existing installation. The attached Compose bundle pins the published multi-platform image digest. See [server operations](../operations.md) for backups and rollback. Deployment is not automatic.

## Validation and limits

Local validation passed: 173 Node tests including real Python agent integration, 91 Python tests, administrator permission regressions, browser sharing and membership checks, Live tooltip and filter checks, desktop/mobile layouts down to 320px, lint, typecheck, and production build. The publication workflow verifies the exact tagged source and native AMD64/ARM64 container smoke tests before publishing.

This revision changes the server/web interface. Physical-device playback and performance were not retested for this release.
