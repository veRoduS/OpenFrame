# OpenFrame 0.18.0

This release improves workspace navigation and editing across slides, playlists, screens, media, users, and groups.

- Slide libraries support list and adjustable-size grid views, plus name and modified-time sorting. Playlist, slide, and screen libraries have filters for larger workspaces.
- Media files and folders can be moved by drag and drop. Nested folders and groups are displayed with clear indentation and easier navigation.
- Admins manage group nesting and membership, user roles, and per-user access from Users & Groups. Admins retain unrestricted access, and access inherited from a parent group includes its nested groups.
- New users receive a randomly generated 12-character password, displayed once when the account is created.
- The slide editor works better on phone-sized screens and supports editable shapes. Weather can use a vertical layout, and slides can include stock tracking.
- Screen details show recovery Wi-Fi only when the connected player supports that service.

Player **0.10.11 remains compatible and unchanged**. The server UI and access controls do not require an APK update. Shapes, stocks, and vertical weather require player 0.10.11 or newer. Physical-device playback was not retested for this release.

Back up the complete application data directory and preserve the existing Compose project name, data volume, `PUBLIC_URL`, `COOKIE_SECURE`, and player pairing. After publication, installations following `ghcr.io/verodus/openframe:latest` can pull and recreate the server:

```sh
docker compose -f compose.registry.yaml pull
docker compose -f compose.registry.yaml up -d
```

Use the same Compose file and project arguments as the existing installation. See [server operations](../operations.md) for backups and rollback. Deployment is not automatic.
