# OpenFrame 0.16.0

This release adds hierarchical group administration, drag-and-drop organization, new slide widgets, and filters for larger workspaces.

- Admins can manage group membership, promote users to admin, move groups between parents, and fine-tune user access. Parent-group membership inherits access to descendant-group content. Existing superadmin accounts become admins without replacing existing admin identities, credentials, sessions, or ownership.
- Drag users into groups and groups into other groups as an admin. Move media folders and drag individual or selected media files into folders or Unfiled.
- Filter Slides, Playlists, and Screens by name, nested group, and status. Parent selections include descendant branches; filters preserve access permissions. Published slide IDs now correctly drive Live badges and filters.
- Add circle or rectangle shapes with fill, outline, and adjustable rectangle corner radius.
- Use vertical weather with a right-sidebar preset and flexible dimensions.
- Add stock trackers with one encrypted Finnhub key configured by an admin. Quotes share a 15-minute cache during scheduled US trading hours; availability and delay depend on the provider account. Exchange holidays are not specially detected. Live Finnhub credentials have not been tested.

## Upgrade

Back up the entire application data directory before upgrading, including `provisioning.key` when present. Preserve the existing data volume, accounts, and player pairing. Keep the same Compose project name; do not run `down -v`. See [server operations](../operations.md).

Update Pi and Android players to **0.10.11 or newer before publishing slides containing shapes, stocks, or vertical weather**. These features use playlist schema 3. Ordinary playlists remain schema 2; the new player continues supporting schemas 1 and 2. The Android APK is distributed through the dedicated `android-releases` branch and the existing updater, independently of the server image. Install over the existing app using the same signing key; do not uninstall. Android requires installation confirmation.

For HTTPS proxies, retain the correct browser-facing `PUBLIC_URL` and `COOKIE_SECURE=true`; recreate the server container after configuration changes. Recovery Wi-Fi is a Pi feature; Android uses its system network settings.

The container publication includes AMD64 and ARM64 images and updates `ghcr.io/verodus/openframe:latest`. Use the attached digest-pinned Compose bundle for reproducible installation. For rollback, retain a stopped, pre-upgrade data backup and the previous image digest; test restoration in a separate project.

## Validation and limits

Local checks passed: 171 Node tests, 91 Python tests, 27 native Android tests, authorization and account migration regressions, browser drag-and-drop and filtering checks, widget rendering, player startup, typecheck, lint, and production build. Weather and stock-provider browser responses were mocked. GitHub runs the release checks and native AMD64/ARM64 container smoke tests before publishing images.

Physical Pi/Android playback, device sleep behavior, and APK installation still require device acceptance. This release has not been validated for physical-device performance.
