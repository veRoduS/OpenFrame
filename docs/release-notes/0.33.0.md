# OpenFrame 0.33.0

This server milestone brings the slide editor, multi-site library controls and
administrator history improvements together. It includes the previously local
server revisions through 0.32.4 and shared player rendering changes in 0.15.10.

## Changes

- Add a slide editing ribbon with insertion tools, portrait orientation, font
  family/size, bold, italic, underline, line spacing, alignment and color.
- Support live numeric metric tokens inside text sentences, using existing
  store-relative feed resolution and authorization.
- Delete selected unlocked canvas layers with the Delete key. New slides remain
  unsaved drafts until edited and explicitly saved.
- Default new metric widgets to header cards while preserving saved simple
  widgets, with explicit conversion and whole-number/currency/percentage presets.
- Automatically grant the site's access group screen access during approval,
  first site assignment and transfers; remove previous recipients during moves.
- Assign View or Edit access to up to 100 selected slides atomically, retaining
  other recipients and ownership and checking linked-content sharing permissions.
- Standardize filters across Slides, Playlists, Screens and Media. Site stays
  visible on mobile, selections persist per page/account, and Clear filters resets
  the site and folder scope alongside other filters.
- Add administrator-only Audit & history with search, actor/resource/action/date
  filters, before/after review and atomic restoration for supported content and
  sharing operations. Newer conflicting edits prevent restoration. Uploads,
  deletions, credentials, device operations and configuration are audit-only.
- Record owner feedback and future feature suggestions in the ideas list;
  PowerPoint/PDF import, QR engagement tracking and persistent zones are ideas,
  not features shipped in this release.

## Compatibility and upgrade

- Existing manifest schemas and saved widget rendering remain supported.
- Update Android/Pi players to **0.15.10 or newer** before using metric sentences
  or italic/underline/line spacing. Older players retain their older text behavior.
- Existing central-store ingestion, configurable feed limits, connection resets
  and Android kiosk improvements are preserved. Resetting a data connection also
  disconnects text bindings without removing their layout or sentence.
- History begins after this version is installed. Its SQLite records are included
  in normal database backups; it cannot reconstruct older edits or deleted files.
- Stop the server and back up its complete data volume before upgrading. Deploy
  the versioned image or attached digest-pinned Compose bundle, preserving that
  volume. Android updates still require installation confirmation on the device.

## Rollback and validation limits

Keep the previous server image and a stopped-volume backup. For a full rollback,
stop this version, restore the matching backup and run the previous image. A
rollback loses changes made after the backup; export or preserve newer data first.

Automated server, player, authorization, audit, site-association and desktop/mobile
browser checks cover the changes. The publication workflow verifies containers
and publishes AMD64/ARM64 images plus a digest-pinned Compose archive. Physical
Android TV and Pi performance/long-run hardware acceptance for the new rendering
features remains unverified; hardware-specific behavior is experimental. This
release does not claim physical panel visibility from player telemetry and does
not automatically deploy to an existing server.
